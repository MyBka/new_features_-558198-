# Описание решения
Основная идея заключается в том, чтобы находить **периметры** и **площади** у таких геометрических фигур, как: треугольник, окружность, квадрат и прямоугольник. (*Также для прямоугольника требуется найти диагональ*)
Для этого мы создаем для **каждой** геометрической фигуры отдельный файл, в котором будем записывать функции, возвращающие нам площади и периметры (*и диагональ у прямоугольника*).

# Описание функций
Весь список функций можно распределить на следующие блоки:

## 1. Функции подсчета площади
Здесь, для каждой фигуры формула своя, покажем это:
**Окружность**
```
def area(r):
    return math.pi * r * r
```
Функция подсчета площади окружности, принимает параметр r - радиус, возвращает площадь: pi*r^2 
```print(area(3))``` = 9*pi

**Прямоугольник**
```
def area(a,b):
    return a * b
```
Функция подсчета площади прямоугольника принимает два числа a,b - стороны фигуры и возвращает их произведение (площадь): a*b'
```print(area(3,4))``` = 12

**Квадрат**
```
def area(a):
    return a * a
```
Функция подсчета площади квадрата принимает параметр a - сторона фигуры и возвращает ее площадь (квадрат стороны): a^2 или a*a
```print(area(4))``` = 16

**Треугольник**
```
def area(a,h):
    return (a*h)/2
```
Функция подсчета площади треугольника принимает параметры a и h - сторона и высота треугольника прилегающая к стороне a, и возвращает его площадь (полупроизведение высоты на сторону, к которой она прилегает): (a*h)/2
```print(area(2,4))``` = 4

## 2. Функции подсчета периметра
Все эти функции, *за исключением периметра окружности*, представляют из себя сумму всех сторон и выглядят следующим образом (*пример для треугольника*):
```
def perimeter(a,b,c): //На вход подаются длины нужных сторон (не обязательно всех, для квадрата, например, достаточно лишь одной)
    return a + b + c //Используем формулу периметра - сумма длин всех сторон
```

И лишь для окружности функция уникальна:
```
import math
def perimeter(r): //На вход подается лишь радиус
    return 2 * math.pi * r //Используем формулу периметра для окружности
```
Например, для треугольника при входных данных: 2, 3, 4 - периметр будет равен 9 ```print(perimeter(2,3,4))``` = 9
Для окружности радиуса = 3 - периметр равен 6*pi ```print(perimeter(3))``` = 6 x pi

## 3. Функция подсчета диагонали (для прямоугольника):
Функция выглядит следующим образом:
```
def diagonal(a,b):
    return sqrt(a**2 + b**2)
```
Здесь на вход подаются два параметра a, b - длина и ширина прямоугольника, воспользовавшись [теоремой Пифагора](https://www.yaklass.ru/p/geometria/8-klass/ploshchadi-figur-9235/teorema-pifagora-dokazatelstvo-9225/re-c8adcccc-87a7-47f4-ae00-4d42ac40b985), выводим длину диагонали.
Так например при входныхх данных: 3,4 - длина диагонали = 5: sqrt(3^2 + 4^2) = 5 ```print(diagonal(3,4))``` = 5
